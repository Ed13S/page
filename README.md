# Circular Functions – Methods Revision Course

A self-contained interactive course for GitHub Pages.

## Publish with GitHub Pages
1. Create a new GitHub repository (for example `circular-functions-course`).
2. Upload `index.html` to the top level of the repository.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then Save.
6. Wait for the Pages deployment, then use the site URL shown in Settings → Pages.

The course uses only HTML, CSS and JavaScript. It needs no build tools, server, API keys or paid services.

## Progress
Lesson completion and quiz scores are stored in the browser's local storage on the device being used. They are not sent to a server and will not automatically sync between devices.
